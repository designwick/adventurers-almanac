# The Adventurers’ Almanac

A private, single-page archive of campaigns, sessions, characters, group-chat statistics, and assorted table lore.

## Local preview

Open `index.html` in a modern browser. The site is self-contained apart from its Google Fonts stylesheet.

## Privacy

This project contains personal photographs and group-chat-derived material. Keep the repository private and use access-controlled hosting when sharing it.
